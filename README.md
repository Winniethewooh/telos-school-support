## 문제와 접근

문헌조사와 교육 현장 인터뷰를 바탕으로 난청 학생의 학교생활에서 발생하는 어려움을 분석했습니다. 학생·교사·보건교사의 사용 맥락을 나누고, 사용자 흐름과 화면을 설계한 뒤 프로토타입으로 구체화했습니다.

- 소통과 학습 참여를 지원하는 화면 및 사용자 흐름 설계
- 난청 학생과 건청 학생, 교사와 보건교사를 고려한 역할별 기능 기획
- 긴급 상황 알림과 학교생활 지원 기능 설계
