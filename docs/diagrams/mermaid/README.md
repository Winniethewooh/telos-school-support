# 담다 다이어그램 — Mermaid 복원본

보관된 클래스 이미지, 시퀀스 PDF 10쪽, 드라이브의 미션빙고 이미지에서 **12개 다이어그램을 코드로 복원**했습니다. 당시 작성한 Mermaid 원본 소스가 아니며, 원본의 메시지·참여자·클래스·관계를 기준으로 옮긴 복원본입니다.
